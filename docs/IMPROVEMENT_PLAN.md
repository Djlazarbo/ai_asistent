# Job Hunter — общий план улучшений (v2, 22.11.2026)

Один источник правды по развитию бота. Заменяет предыдущую версию плана; раздел про поиск сохранён и встроен в общую структуру.

**Точка старта:** прод 1.2.2 (изоляция лент, неблокирующий поиск, tg_notify, SSH/ufw hardening). Тесты: 354 unit, зелёные. Жалоба-драйвер: «вакансии не очень мониторятся у пользователей» + «поиск работает криво».

**Правила (неизменны):** одна БД, изоляция через `user_*`-таблицы · никаких глобальных фильтров/порога/опыта hh — только per-user · не ломать non-PM роли (маркетинг/безопасность) · секреты не коммитить · деплой на прод — с подтверждением владельца.

## Дорожная карта (ориентир)

**Неделя 1 — «юзер видит вакансии и понимает, почему»**
1.2 + 1.3 (диагностика) → 2.1 (валидация слов) → 2.2 (честный daily) → 3.1 (backfill каждые 2–3ч) → 4.1 (instant пуши) → 6.1 (владелец: GitHub) → 5.1 (poller-сборка)

**Неделя 2 — «поиск ловит больше и не мусорит»**
2.4 (инкрементальный HH) → 3.2 (two-stage скоринг) → 2.5 (junk per-user) → 2.6 (Getmatch) → 1.1 (онбординг-визард)

**Неделя 3 — «надёжность и деньги»**
5.2–5.5 (healthchecks, логи, монитор, дрель бэкапов) → 3.3–3.4 ($-метрики, автоподсказка порога) → 4.2–4.3 (плотность пушей, дайджест)

**Неделя 4 — «аналитика и полировка»**
7.1–7.2 → 1.4–1.5 (empty states, действия в дайджесте) → 2.7–2.8 → остатки P2 по способностям.

## Критерии успеха (через месяц)

1. У каждого активного юзера лента растёт **без нажатия «Искать»** (≥ N новых карточек/день при живых источниках).
2. Юзер может одной кнопкой увидеть, **почему** у него мало/много вакансий, и что поправить.
3. Ни одно ключевое слово не отбрасывается молча — всегда видна валидация.
4. Бот отвечает всем во время любого поиска (уже сделано в 1.2.2 — держать тестом).
5. Расход DeepSeek и здоровье пайплайна видны владельцу ежедневно (jh_digest).
6. Non-PM юзер (если появится) получает вакансии своей роли (junk per-user).

## Чего не делаем

Отдельные БД на юзера · глобальные фильтры/порог/опыт hh · отключение источников «на всякий» · коммит секретов · force-push/wipe · рефакторинг bot.py «ради красоты» (только точечный, по ходу фич).
